# Gini coefficient (Hệ số Gini)

**Định nghĩa:** Gini = 2 · AUC − 1: 0 là ngẫu nhiên, 1 là hoàn hảo. Cùng thứ hạng với AUC. **Khác** [[Gini impurity]] dùng để tách nút cây.

**Suy ra từ:** [[AUC]]

**Trong đồ án:** Báo cáo cùng AUC (`metrics.py`); thứ hạng mô hình giống hệt AUC.
