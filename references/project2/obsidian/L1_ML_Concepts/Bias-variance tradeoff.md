# Bias-variance tradeoff (Đánh đổi bias – variance)

**Định nghĩa:** Sai số kỳ vọng = bias² + variance + nhiễu. Bagging chủ yếu giảm variance; boosting chủ yếu giảm bias.

**Suy ra từ:** [[Generalization]]

**Nguồn:** [[Breiman 2001]] · [[Friedman 2001]]
