# Feature scaling (Chuẩn hóa thang đo)

**Định nghĩa:** Đưa các đặc trưng về cùng thang đo (ví dụ trung bình 0, độ lệch chuẩn 1). Quan trọng với mô hình dùng khoảng cách hoặc hệ số tuyến tính; cây không nhạy.

**Suy ra từ:** [[Feature]]

**Trong đồ án:** `StandardScaler` ở tầng B.1.
