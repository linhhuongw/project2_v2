# Wilcoxon signed-rank test (Kiểm định Wilcoxon hạng có dấu)

**Định nghĩa:** Kiểm định phi tham số cho dữ liệu ghép cặp: so sánh hai mô hình trên cùng các tập dữ liệu/fold bằng hạng của các chênh lệch. Khác với kiểm định tổng hạng Wilcoxon (hai mẫu độc lập).

**Suy ra từ:** [[Hypothesis testing]]

**Trong đồ án:** So sánh từng cặp mô hình (Demšar 2006), kèm hiệu chỉnh Holm.
