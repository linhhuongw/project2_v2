# Abstract

Credit scoring is the task of estimating how likely a borrower is to default, and Logistic Regression is the industry standard model for it. Machine learning models such as Random Forest and gradient boosting are expected to perform better, but existing comparison studies often use only a few small datasets, evaluate with a single type of metric and lack suitable statistical tests. This project takes a controlled comparison approach and evaluates every model with the same data splitting, preprocessing and evaluation procedure, because differences in results reflect differences between models only when every model is evaluated under the same conditions. The project builds a reproducible pipeline over seven public datasets, in which every step that learns from data is fitted only on the training part of each fold. It then compares seven models with default parameters using multiple metrics, the Friedman test and post-hoc tests on ranks, and checks for data leakage and overfitting. The results show that CatBoost is the best model overall, ranking first by AUC on five of the seven datasets. The largest improvement comes from moving from a linear model to tree-based models, up to 0.17 AUC, while the differences among tree-based models are not statistically confirmed. Logistic Regression remains competitive on datasets with a near-linear signal or with drift over time. The project also finds leakage through missing-value patterns in the HMEQ dataset and shows that the comparison conclusions do not change after the leakage is removed.
